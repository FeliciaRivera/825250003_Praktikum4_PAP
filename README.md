## Deskripsi

Website ini merupakan tampilan profil mahasiswa yang dibuat menggunakan **HTML, CSS, dan JavaScript**.

Website memiliki dua tombol utama:

1. **Tampilkan ID**  
   Menampilkan sebuah persegi panjang yang berisi nama dan NIM mahasiswa.

2. **Hapus ID**  
   Menghapus persegi panjang ID yang telah ditampilkan.

Selain fitur utama tersebut, website juga menampilkan profil mahasiswa, foto, keahlian dan minat, serta tabel jadwal mata kuliah.
